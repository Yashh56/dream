## D26-01: Host-bound Generated git text

Status: implemented

Problem: generated text and its in-flight requests are keyed by path without
the Host, and background warming drops its Host before generation. Identical
paths on different Hosts can share text or send a request to the wrong Host.

Scope: carry a captured Host through the commit draft, pull-request details,
background warming, cache key and Route client. Keep existing generation and
git-write behavior. Local means the home Host; no path-only inference after a
Project is identified.

Completion criteria:

- Commit and pull-request generations and cache entries are isolated by Host.
- Background warming retains its Host across asynchronous status reads.
- Tests cover same paths on different Hosts and shared requests on one Host.
- Relevant tests, typecheck and lint pass.

Validation: 24 tests passed across generated text, commit draft and Project
resources. `pnpm typecheck` and Biome checks on changed source files passed.
No live model or SSH Host was invoked.

Remaining/deferred: none within scope.

## D26-02: Terminal session command observation

Status: implemented

Problem: the terminal view owns the command refresh timer. Unmounting a compact
terminal sheet cancels a pending refresh while its touched shell continues.

Scope: make command observation follow the Terminal session lifetime, retain
the existing quiet-period heuristic and preserve shell transport, output
buffering and navigation ownership. Settle pending refresh on terminal close;
discard it if its Project is removed.

Completion criteria:

- Input followed by view detachment and output still refreshes Project resources.
- Closing a terminal with pending command work refreshes its Project; removing
  the Project cancels the work without refreshing a removed Project.
- Automatic terminal responses do not mark a session touched or start a timer.
- Relevant tests, typecheck and lint pass.

Validation: 30 tests passed across terminal sessions, store actions, output,
navigation, Host and Project removal, and the terminal client. The session
and store tests exercise detached observation, terminal close, Project removal
and automatic responses. Typecheck and changed-file Biome checks passed.
The compact layout was not inspected in a live browser or desktop.

Remaining/deferred: no implementation work; native compact-layout inspection
remains useful.

## D26-03: Project opening attempt lifetime

Status: proposed

Problem: delayed path resolution or a native picker can complete after the
dialog is dismissed or its Host/path is changed, opening a stale Project.

Scope: one attempt owner controls typed and native opens, and rejects stale
completions after dismissal, Host/path changes or a replacement attempt. Keep
Host connection and Workspace document ownership; preserve existing path
completion and older-Host compatibility. Folder listing retains its own
freshness rule, with late results invalidated on disposal or unavailability.

Completion criteria:

- Cancel, context change or a newer attempt prevents a late open.
- A failed connection and a failed directory resolution leave the dialog usable.
- The native picker and typed path each honor attempt lifetime.
- Relevant tests, typecheck and lint pass.

Validation: pending.

Remaining/deferred: implementation and validation.
